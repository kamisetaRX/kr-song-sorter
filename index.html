Source Code | Based on Execfera's Touhou Project Character Sorter | Clear Save Data

A song sorter for the entire Kamen Rider franchise

You can hover over some filter options to get a better description.

Use the filters to select which eras, series, and/or song types you want to include, then click Start.

Click Tie if you either like them equally or don't know either of them.

Listen to each song using the embedded YouTube player, then click the song title card to pick your favourite.



Note, that if you include everything, you will be making well over 1000+ comparisons, so it will take a long time.

I highly recommend you keep "Exclude CD-Only Songs" checked, especially if you include the Showa Era.



Keyboard controls during sorting: H / ← (pick left)   J / ↓ (undo)   K / ↑ (tie)   L / → (pick right)   S (save progress).

Before sorting: S / Enter (start)   L (load saved progress).

1 / 2 / 3 always correspond to the first, second, and third buttons.
